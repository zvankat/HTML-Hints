# HTML-подсказки
Все теги HTML, которые вообще существуют (ну или почти все)

---

**Структура документа**
`<!DOCTYPE>` - объявление типа документа  
`<html>` - корневой элемент страницы  
`<head>` - контейнер для метаданных  
`<body>` - тело документа (все, что видит пользователь)  
`<title>` - заголовок вкладки браузера  
`<meta>` - метаданные (кодировка, описание, ключи)  
`<base>` - базовый URL для относительных ссылок  

---

**Текст и заголовки**
`<h1>...<h6>` - заголовки (от самого важного до самого мелкого)  
`<p>` - абзац текста  
`<br>` - перенос строки  
`<hr>` - горизонтальная линия (тематический разрыв)  
`<pre>` - предварительно отформатированный текст (сохраняет пробелы и переносы)  
`<blockquote>` - длинная цитата  
`<q>` - короткая цитата в тексте  
`<cite>` - источник цитаты (курсивом)  
`<address>` - контактная информация  

---

**Форматирование текста**
`<b>` - жирный текст (просто визуально)  
`<strong>` - важный текст (жирный + смысловое выделение)  
`<i>` - курсив (просто визуально)  
`<em>` - акцентированный текст (курсив + смысловое выделение)  
`<mark>` - выделенный (подсвеченный) текст  
`<small>` - мелкий текст (комментарии, сноски)  
`<del>` - удаленный текст (зачеркнутый)  
`<ins>` - вставленный текст (подчеркнутый)  
`<sub>` - подстрочный текст (H₂O)  
`<sup>` - надстрочный текст (м²)  
`<u>` - подчеркнутый текст  
`<s>` - зачеркнутый текст (неактуальное)  
`<code>` - код (моноширинный шрифт)  
`<kbd>` - клавиши с клавиатуры  
`<samp>` - пример вывода программы  
`<var>` - переменная в коде  

---

**Списки**
`<ul>` - маркированный список  
`<ol>` - нумерованный список  
`<li>` - элемент списка  
`<dl>` - список определений  
`<dt>` - термин в списке определений  
`<dd>` - определение термина  

---

**Ссылки и навигация**
`<a>` - гиперссылка  
`<nav>` - навигационное меню  
`<link>` - подключение внешних файлов (css, иконки)  

---

**Изображения и медиа**
`<img>` - картинка  
`<picture>` - контейнер для адаптивных изображений  
`<source>` - источник медиа для `<picture>`, `<audio>`, `<video>`  
`<figure>` - иллюстрация с подписью  
`<figcaption>` - подпись к иллюстрации  
`<audio>` - аудио  
`<video>` - видео  
`<track>` - субтитры для видео  
`<map>` - карта-изображение с кликабельными областями  
`<area>` - область на карте-изображении  
`<svg>` - векторная графика  

---

**Таблицы**
`<table>` - таблица  
`<caption>` - заголовок таблицы  
`<thead>` - шапка таблицы  
`<tbody>` - тело таблицы  
`<tfoot>` - подвал таблицы  
`<tr>` - строка таблицы  
`<td>` - ячейка таблицы  
`<th>` - ячейка-заголовок  
`<col>` - колонка таблицы (для стилей)  
`<colgroup>` - группа колонок  

---

**Формы**
`<form>` - форма для отправки данных  
`<input>` - поле ввода  
`<textarea>` - многострочное поле ввода  
`<button>` - кнопка  
`<select>` - выпадающий список  
`<option>` - элемент выпадающего списка  
`<optgroup>` - группа элементов в списке  
`<label>` - подпись к полю ввода  
`<fieldset>` - группа полей формы  
`<legend>` - заголовок группы полей  
`<datalist>` - автодополнение для input  
`<output>` - результат вычисления  
`<progress>` - прогресс выполнения  
`<meter>` - значение в диапазоне  

---

**Семантические теги HTML5**
`<header>` - шапка сайта или раздела  
`<footer>` - подвал сайта или раздела  
`<main>` - основное содержание (уникальное для страницы)  
`<section>` - раздел документа  
`<article>` - независимая, самодостаточная часть  
`<aside>` - боковая панель (не основной контент)  
`<details>` - раскрывающийся блок  
`<summary>` - видимый заголовок для details  
`<dialog>` - диалоговое окно  

---

**Работа с кодом и скриптами**
`<script>` - подключение JavaScript  
`<noscript>` - контент, если скрипты отключены  
`<canvas>` - область для рисования через JS  
`<template>` - шаблон (не рендерится до активации)  
`<slot>` - слот для веб-компонентов  

---

**Метаданные и подключения**
`<style>` - CSS стили внутри документа  
`<div>` - универсальный блок  
`<span>` - универсальный контейнер в строке  

---

**Устаревшие (но могут встречаться)**
`<center>` - центрирование (был, но не надо так)  
`<font>` - шрифт (был, но не надо так)  
`<big>` - крупный текст (был, но не надо так)  
`<strike>` - зачеркнутый (вместо него `<del>` или `<s>`)  
`<frame>`, `<frameset>`, `<noframes>` - фреймы (не используй)  

---

**Редкие и специфические**
`<bdi>` - изоляция текста для разных направлений письма  
`<bdo>` - переопределение направления текста  
`<ruby>` - иероглифы с пояснениями (для азиатских языков)  
`<rt>` - пояснение для ruby  
`<rp>` - скобки для браузеров без поддержки ruby  
`<wbr>` - место возможного переноса строки  
`<time>` - время или дата  
`<data>` - машинно-читаемые данные  

---
